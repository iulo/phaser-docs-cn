# 创建新的用户组件文件 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/user-components/user-components-create-file)

这些步骤是创建新的用户组件文件:

1. 打开[New File dialog](/editor/workbench/new-file-dialog)。
2. 选择 ** User 组件文件 ** 选项。此选项打开了 ** 新用户组件文件 ** 对话框。
3. 在新对话框中,选择新文件的位置 。
4. 写入新文件的名称。 `.components` 扩展名如果没有设置,则自动添加 。
5. 按 ** Create ** 按钮。 文件将在 [User Components Editor](/editor/scene-editor/user-components/user-components-editor) 中创建并打开。

![New User Components file.](https://cdn.phaser.io/editor-docs/scene-editor-user-components-new-file-20221101.webp)


#### 警告( 警告) {#warning}
`*.components`文件只被编辑器使用,建议将其排除在游戏最终发行之外,只有生成的JavaScript文件与游戏文件相关.

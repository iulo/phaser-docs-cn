### BatchHandlerQuadRenderOptions {#BatchHandlerQuadRenderOptions}

#### BatchHandlerQuadRenderOptions {#batchhandlerquadrenderoptions}


**说明:**

配置四映射的着色器能力的选项 。

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| clampFrame | boolean | 是 | 是否夹住纹理帧。 这可以防止线性过滤导致出血, 这对于瓦片大多有用 。 |
| wrapFrame | boolean | 是 | 是否包扎纹理帧。 这是 TileSprites 所必需 。 |

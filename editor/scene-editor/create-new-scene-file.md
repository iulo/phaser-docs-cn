# 创建新场景文件 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/create-new-scene-file)

这些步骤是创建新场景文件的步骤 :

1. 打开[New File dialog](/editor/workbench/new-file-dialog)。
2. 选择 ** 场景文件 ** 选项。此选项打开了 ** 新场景文件 ** 对话框 。
3. 在新对话框中,选择新文件的位置 。
4. 写入场景文件的名称。 `.scene` 扩展名如果没有设置, 则自动添加 。
5. 按 ** Create ** 按钮, 文件将在场景编辑器中创建并打开 。

![New scene file.](https://cdn.phaser.io/editor-docs/scene-editor-new-file-04102020.webp)


## 设置 {#settings}

当创建新场景时, 它会使用默认设置。 但是, 如果有其他场景文件, 一些一般设置会从最新的修改场景中取出。 这样可以保留您工程所有场景的相同一般设置 。 未来, 我们应当执行更好的设置一般工程设置的方法 。

这些是创建新场景文件时复制的设置 :

* **borderX**
* **borderY**
* **borderWidth**
* **borderHeight**
* **compilerOutputLanguage**
* **compilerInsertSpaces**
* **compilerTabSize**

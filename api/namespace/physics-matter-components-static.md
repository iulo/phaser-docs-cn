### isStatic {#isStatic}

#### \<instance> isStatic() {#instance-isstatic}


**说明:**

如果机体是静态的,返回`true`,否则返回`false`为动态机体.


**返回值:** boolean - 如果物理体是静态的,则`true`,否则则`false`.

### setStatic {#setStatic}

#### \<instance> setStatic(value) {#instance-setstaticvalue}


**说明:**

改变物理体,要么是静态的`true`,要么是动态的`false`.

**参数:**
| 名称 | 类型 | 可选 | 说明 |

| value | boolean | 否 | 将物理体设置为静态的`true`,或`false`使其动态. |

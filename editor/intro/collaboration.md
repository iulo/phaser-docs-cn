# 协作开发 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/intro/collaboration)

很高兴你合作!

你可以通过报告问题、提供想法、发送代码修改、编写教程来帮助我们。不管怎样,你认为这可以改进产品或更容易地采用产品。

报告问题的主要地点是[Phaser Editor's bug tracker repository in GitHub](https://github.com/phaserjs/phaser-editor-issues).

也可以通过社交渠道联系我们:

[X @phaser_](https://twitter.com/phaser_)

[Phaser Discord](https://phaser.io/community/discord)

[YouTube channel](https://www.youtube.com/@PhaserYouTube)

或者写一封邮件给`support@phaser.io`

# 视图 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/views)

视图是可用于任何目的的面板。在 IDE 中,它们大多用于显示结构化数据或对象的属性。

IDE中有几种观点: 部分内容显示与活动编辑器相关的内容,与工作台中选定元素相关的内容,或项目内容.

此时,视图可以调整大小,但不能拖曳、停靠或堆放到工作台的其他地方,也可以关闭和打开(如在其他IDE中所做的那样)。我们应该在未来的IDE版本中添加这些特性。

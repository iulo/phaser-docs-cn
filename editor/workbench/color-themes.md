# 配色主题 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/color-themes)

Phaser编辑器支持一些浅色和暗色的主题。您可以通过按下`Ctrl+2`键或者选择[Main menu](/editor/workbench/main-menu)中的**选择颜色主题**选项来选择一个颜色主题。

![Color theme dialog.](https://cdn.phaser.io/editor-docs/workbench-color-themes-04072020.webp)

色彩主题由插件贡献。 我们应该在未来的插件开发者指南中写下如何创建您的自定义主题 。

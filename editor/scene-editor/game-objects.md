# 游戏对象类型 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/game-objects)

场景编辑器正在积极开发中,只支持一套非常基本的游戏对象类型,最终,我们应当增加更多的类型和更多的属性.

然而,预制体工作允许使用预制体作为黑匣子的方式。这个黑匣子可以添加到场景中,但您可以提供自定义执行。此技术包含在[Using a prefab as a black box](/editor/scene-editor/prefabs/prefab-black-box)的章节中。此外,您还可以添加新的游戏对象[via plugins](/editor/misc/plugins).

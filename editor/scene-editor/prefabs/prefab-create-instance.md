# 创建预制体实例 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/prefabs/prefab-create-instance)

您可以将 Prefab 文件丢入现场, 从文件视图或块视图中拖曳它, 从而创建一个预制体实例 。

当活动的编辑器是场景编辑器时,块视图会显示[Asset Pack file](/editor/asset-pack-editor/asset-pack-file)项目和Prefab文件:

![Create prefab instance.](https://cdn.phaser.io/editor-docs/scene-editor-prefab-create-instance-04202020.webp)

您可以用 ** Open Prefab ** 命令打开一个预制体实例的 Prefab 文件。 您可以在上下文菜单中按下 `F` 键或执行命令, 在 ** Prefab ** 次菜单中:

![Open prefab file of instance.](https://cdn.phaser.io/editor-docs/scene-editor-prefab-open-prefab-file-06082020.webp)

检查器视图显示选定对象的每个预制体(和预制体)变量的一节。在区域菜单中,您可以单击 ** Open Prefab ** 选项:

![Open prefab file by clicking on prefab name in the Inspector.](https://cdn.phaser.io/editor-docs/scene-editor-prefab-open-prefab-file-from-inspector-20230627.webp)

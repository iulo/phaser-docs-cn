# 网格布局工具 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/layout-tools/layout-tools-grid)

网格布局工具将对象置于网格中。您可以更改一些参数,如编目或数字列和行。

从此配置开始 :

![Grid layout start configuration.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-grid-start-07092021.webp)

不同的布局是:

**线条**

排列列中的项目。 ** Pading ** 参数是列之间的间距 :

![Row layout.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-grid-row-07092021.webp)

**栏**

排列列中的项目。 ** 平板 ** 参数是行之间的间距 :

![Row layout.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-grid-column-07092021.webp)

**网格**

排列网格(表)中的项目。 ** Columns ** 参数设置列数。 项目从列开始, 计数列数。 行数是依数或列数和项目数的依存而计算。

**Cell Width**和**CellHeight**参数设定了网格的单元格大小。如果是 0,大小则以所有物体的最大宽度和高度计算。

**Padding**参数是单元格之间的间距。

![Grid layout.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-grid-grid-07092021.webp)

# 添加和删除帧 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/animations-editor/adding-deleting-frames)

动画制作最快的方法是使用 [provided automatic process](/editor/animations-editor/auto-build-animations)。 然而, 您可能想要更改动画的帧, 删除, 或者添加它们 。

要删除几个框架,请在大纲视图中选择它们,并执行**Delete**命令(按下`Del`键,或在上下文菜单中选择**Delete **)。

要添加帧,请选择动画,然后选择在开始或结尾插入:

![Add frames to the animations.](https://cdn.phaser.io/editor-docs/animations-add-frames-1.webp)

它打开了与图像相关的所有资源(框架、纹理图、图示表)的对话框。您可以选择添加的框架 :

![Add frames to the animations.](https://cdn.phaser.io/editor-docs/animations-add-frames-2.webp)

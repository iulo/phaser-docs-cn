# 创建资源包文件 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/asset-pack-editor/create-asset-pack-file)

Phaser编辑器提供的项目模板至少包含一个[Asset Pack file](/editor/asset-pack-editor/asset-pack-file)。您可以使用它配置您的项目的资源。但是,如果您要在游戏的某个时刻装入一组资源,而在游戏的另一时刻装入另一组资源,您可以创建一个新的[Asset Pack file](/editor/asset-pack-editor/asset-pack-file)。

要创建新文件, 请打开 [New File dialog](/editor/workbench/new-file-dialog) 并选择 ** Asset Pack 文件 ** 选项。 它将打开 ** 新资源包文件 ** 对话框 :

![New Asset Pack file dialog.](https://cdn.phaser.io/editor-docs/asset-pack-editor-new-file-01012022.webp)

选择要创建文件并写入文件名称的文件夹。 您不需要在文件上添加 `.json` 扩展名, 对话框会自动这样做 。

当文件创建时,IDE会在[Asset Pack Editor](/editor/asset-pack-editor/intro)中打开.

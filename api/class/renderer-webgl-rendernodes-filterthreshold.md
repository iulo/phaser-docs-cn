# FilterThreshold {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/renderer-webgl-rendernodes-filterthreshold)

这个 RenderNode 使游戏对象的每个像素都转换成完全不透明或完全透明, 其亮度低于 `edge1` 的像素会被丢弃, 高于 `edge2` 的像子被保留, 介于两者之间的像素被平稳插入。 效果可以选择反转, 使亮度像素被丢弃, 而不是暗色的像素。 见 [Phaser.Filters.Threshold](/api/class/filters-threshold) 。

**构造函数**

`new FilterThreshold(manager)`

**参数**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| manager | [Phaser.Renderer.WebGL.RenderNodes.RenderNodeManager](/api/class/renderer-webgl-rendernodes-rendernodemanager) | 否 | 这个RenderNode的经理 |

## 公开方法 {#public-methods}

### setupUniforms {#setupUniforms}

#### \<instance> setupUniforms(controller, drawingContext) {#instance-setupuniformscontroller-drawingcontext}


**说明:**

设置阈值过滤器所需的 WebGL 遮蔽制服 。

将下限边(`edge1`),上限边(`edge2`),反向旗传到碎片遮蔽器上,以便能对当前框架应用正确的阈值计算.

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| controller | [Phaser.Filters.Threshold](/api/class/filters-threshold) | 否 | 提供统一值的过滤控制器 。 |
| drawingContext | [Phaser.Renderer.WebGL.DrawingContext](/api/class/renderer-webgl-drawingcontext) | 否 | 当前绘图背景 。 |


**Overrides:** Phaser.Renderer.WebGL.RenderNodes.BaseFilterShader#setupUniforms

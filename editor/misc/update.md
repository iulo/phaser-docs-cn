# 更新编辑器 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/misc/update)

当您启动服务器时, 它会连接到互联网上的更新网站, 并检查是否有新版本。 如果有新版本, 它会显示一个带有版本编号的信息 和发布注释的一些头条 。

[Phaser Editor Desktop](/editor/intro/distributions#phaser-editor-desktop)发行版显示有消息时有新更新,但您应该手动下载新版本.

在编辑器的v3中,您可以选择安装/更新来自国家预防机制的[Phaser Editor Core](/editor/intro/distributions#phaser-editor-core)。然而,在Phaser编辑器v4中却无法使用。

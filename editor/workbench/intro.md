# 简介 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/intro)

工作台是IDE所有部分的总称:编辑器,视图,对话框,菜单,命令,主题,扩展,存储。是IDE中包含的工具的地下室.

如果您是 Phaser 编辑器 v2 用户, 这个新版本的 IDE 应该会令您非常熟悉。 它的布局类似, 但会消除一个通用的 IDE 的所有复杂度, 并向您显示您所需要的工具 。

![Workbench overview](https://cdn.phaser.io/editor-docs/workbench-overview-20241005.webp)

IDE 包含其他游戏开发工具中的元素:

* "大纲"视图显示活动编辑器的内容,但结构层次分明.
* 检查器视图显示活动编辑器或活动视图中所选择对象的属性。我们可以说,您可以在 IDE 视图中编辑的所有对象都会修改 。
* Blocks 视图显示您可以用来构建活动编辑器对象的元素。 如果活动编辑器是 Scene 编辑器, 则 Blocks 查看会显示您可以投放到现场的资源。 如果活动编辑器为 [Asset Pack Editor](/editor/asset-pack-editor/intro)Z, 那么它显示您可以导入到 [Asset Pack file](/editor/asset-pack-editor/asset-pack-file)的文件。 也许这个视图在市场上并不常见, 但概念很简单 。
* 文件视图显示工程的文件。 它与其他文件探索器一样。 它允许删除、 重命名、 移动、 上传文件。 打开编辑器中的文件和其他文件相关动作。 和其他视图一样, 当您选择文件时, 检查器视图显示文件属性和其他动作 。
* [Main toolbar](/editor/workbench/main-toolbar)和[Main menu](/editor/workbench/main-menu)提供了影响当前编辑器或整个IDE的命令(或动作).

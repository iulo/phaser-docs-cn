# Arcade 物理 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/arcade-physics)

Arcade是一个在Phaser中非常流行的物理系统. Phaser编辑器提供了视觉工具,用于创造和配置Arcade物理对象.

您可以创建 `Phaser.Physics.Arcade.Image`或 `Phaser.Physics.Arcade.Sprite` 游戏对象,或者在任何其他游戏对象中启用物理对象.

有了视觉工具,可以改变物理体大小和抵消. 有了检查器视图编辑器,可以调整物理属性,如速度,质量等.

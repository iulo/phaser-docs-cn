# 对齐工具 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/layout-tools/layout-tools-align)

对应工具为在同一行中设置对象提供了快捷键。对齐线可以是以下之一:**Left**、**Center**、**Right**、**Top**、**Middle**和**Bottom**。

让我们看看从这个配置开始的行:

![Example start configuration.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-align-start-07092021.webp)

# 资源包文件 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/asset-pack-editor/asset-pack-file)

资源包文件是游戏中您可以加载的文件的表单(以JSON格式),它内置于Phaser,您无需Phaser编辑器即可使用.

[Learn more about Asset Pack loading in Phaser](/api/class/loader-loaderplugin#pack)

此文件在 IDE 中被密集使用。 [Scene Editor](/editor/scene-editor/intro) 这样的工具取决于资源包文件中提供的信息 。

在项目中可以有多个 [asset pack files](/editor/asset-pack-editor/asset-pack-file) 。 事实上, 在大型游戏中, 将资源分成不同的组( 资源包文件) 并只在需要时加载它们, 是一种好的做法 。

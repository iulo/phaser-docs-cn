# FilterBlocky {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/renderer-webgl-rendernodes-filterblocky)

这个 RenderNode 使输出的布洛克滤波器效果像素, 将输出分为可配置大小的矩形块。 每个块都用从源纹理中取样的一致颜色来填充, 产生反射, 低分辨率外观。 块尺寸和位置偏移由相关的 [Phaser.Filters.Blocky](/api/class/filters-blocky) 控制器驱动 。 见 [Phaser.Filters.Blocky](/api/class/filters-blocky) 。

**构造函数**

`new FilterBlocky(manager)`

**参数**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| manager | [Phaser.Renderer.WebGL.RenderNodes.RenderNodeManager](/api/class/renderer-webgl-rendernodes-rendernodemanager) | 否 | 这个RenderNode的经理 |

## 公开方法 {#public-methods}

### setupUniforms {#setupUniforms}

#### \<instance> setupUniforms(controller, drawingContext) {#instance-setupuniformscontroller-drawingcontext}


**说明:**

设置布洛克滤镜所需的WebGL遮蔽制服.

将当前渲染的目标尺寸通过 `resolution`, 以及包含夹住的块宽度、 块高度和 x/y 位置偏移的 `uSizeAndOffset` 矢量。 块大小值被夹住到最小 1 , 以防止在阴影中逐零 。

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| controller | [Phaser.Filters.Blocky](/api/class/filters-blocky) | 否 | 过滤器控制器提供块大小和抵消值 。 |
| drawingContext | [Phaser.Renderer.WebGL.DrawingContext](/api/class/renderer-webgl-drawingcontext) | 否 | 当前绘图上下文,用于读取渲染目标维度. |


**Overrides:** Phaser.Renderer.WebGL.RenderNodes.BaseFilterShader#setupUniforms

# Triangle {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/gameobjects-triangle)

三角形状是一个游戏对象,可以添加到景物,组或容器中。您可以把它当作游戏中的其他游戏对象,比如对它进行扭动,缩放,或者允许它输入或物理。它为您提供了快速和容易的方法,在游戏中不使用纹理来渲染此形状,同时仍然利用WebGL的完整批量.

此形状支持设置填充颜色和描边颜色。

三角形由3行组成, 组合成三角形。 您可以控制这些线的每个点的位置。 三角形总是关闭, 无法打开面孔。 如果您需要, 请考虑使用多边形 。

**构造函数**

`new Triangle(scene, [x], [y], [x1], [y1], [x2], [y2], [x3], [y3], [fillColor], [fillAlpha])`

**参数**
| 名称 | 类型 | 可选 | 默认值 | 说明 |
| ---- | ---- | -------- | ------- | ----------- |
| scene | [Phaser.Scene](/api/class/scene) | 否 |  | 此游戏对象所属的景点。 一个游戏对象只能一次属于一个景点 。 |
| x | number | 是 | 0 | 这个游戏对象在世界的横向位置. |
| y | number | 是 | 0 | 此游戏对象在世界的垂直位置 。 |
| x1 | number | 是 | 0 | 三角形第一点的横向位置. |
| y1 | number | 是 | 128 | 三角形第一点的垂直位置. |
| x2 | number | 是 | 64 | 三角形第二点的横向位置. |
| y2 | number | 是 | 0 | 三角形第二点的垂直位置. |
| x3 | number | 是 | 128 | 三角形中第三点的横向位置. |
| y3 | number | 是 | 128 | 三角形第三点的垂直位置. |
| fillColor | number | 是 |  | 三角形的颜色会填充,即0xff000表示红色. |
| fillAlpha | number | 是 |  | 三角形的α将填充。 您也可以使用它的 `alpha` 属性设置整个形状的α 。 |

### setTo {#setTo}

#### \<instance> setTo([x1], [y1], [x2], [y2], [x3], [y3]) {#instance-settox1-y1-x2-y2-x3-y3}


**说明:**

设置此三角形的三个顶点的位置,并更新其内部路径数据进行渲染.

**参数:**
| 名称 | 类型 | 可选 | 默认值 | 说明 |
| ---- | ---- | -------- | ------- | ----------- |
| x1 | number | 是 | 0 | 三角形第一点的横向位置. |
| y1 | number | 是 | 0 | 三角形第一点的垂直位置. |
| x2 | number | 是 | 0 | 三角形第二点的横向位置. |
| y2 | number | 是 | 0 | 三角形第二点的垂直位置. |
| x3 | number | 是 | 0 | 三角形中第三点的横向位置. |
| y3 | number | 是 | 0 | 三角形第三点的垂直位置. |


**返回值:** [Phaser.GameObjects.Triangle](/api/class/gameobjects-triangle) - 此游戏对象实例 。

# Box2D 物理 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/box2d-physics)

Box2D一直是游戏业最受欢迎的物理引擎之一. Phaser 已添加此库的支持。 Phaser 团队直接翻译了Box2D的C代码 JavaScript,并刚刚增加了几套公用事业,以整合它与 Phaser API. 爱普.

[Take a look at the Phaser Box2D implementation page](https://phaser.io/box2d)

除了Box2D库之外,团队还在为Phaser编辑器开发工具,允许您以视觉方式创建和配置Box2D物理对象。这是在进行中的工作,但您现在可以开始创建物理场景了。

我们强烈建议你读一下 [official Box2D documentation](https://box2d.org/documentation/) 理解概念和API。 Phaser Box2D API与原Box2D APID非常相似,因此可以使用官方文档来学习如何使用.

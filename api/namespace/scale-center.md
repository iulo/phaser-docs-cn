## 静态函数 {#static-functions}

### CENTER_BOTH {#CENTER_BOTH}

#### CENTER_BOTH: number {#center_both-number}


**说明:**

游戏画布在母版内部横向和纵向都以中心为中心,要做到这一点,母版必须有一个可以计算而不是空的界限.

居中是通过设置游戏画布的左侧边距和顶端属性来实现的,并且不考虑您可能应用的任何其他 CSS 样式.

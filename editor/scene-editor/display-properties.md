# 显示属性 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/display-properties)

**场景显示**部分提供了**场景显示名称**属性.

默认情况下,编辑器中不同的UI查看器会显示场景文件的名称作为场景的显示名称.

使用 ** 场景显示名称 ** 属性, 您可以更改场景的显示名称 。 您可以使用一个描述性更强的名称, 如 ** Level 1: 山** :

![Set the display name of a scene.](https://cdn.phaser.io/editor-docs/scene-editor-scene-display-name-properties-20231205.webp)

显示名称出现在编辑器的不同UI查看器中, 如 ** Go To Scene** 对话框 :

![The scene display name in the go-to scene dialog.](https://cdn.phaser.io/editor-docs/scene-editor-display-name-viewers-20231205.webp)

或者在场景编辑器的块视图中:

![Scene display name in the Blocks view.](https://cdn.phaser.io/editor-docs/scene-editor-scene-display-name-blocks-view-20231205.webp)

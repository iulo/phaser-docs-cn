# 为脚本节点添加约束 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/script-node/script-node-constraints)

脚本节点是建立游戏中可重复使用行为的等级的有力工具,然而,有时需要限制这些节点如何连接或使用来保持游戏逻辑的一致性并避免错误,这在有开发者和设计者在团队中合作时特别有用,并且希望确保节点的连接一致并遵循游戏规则.

为此,我们实施了约束系统,允许您定义哪些脚本节点可以互相连接.

可以在脚本节点中应用两种约束: 限制 :

- 一般限制 : 这些限制可以评价脚本节点的背景, 并决定连接是否有效 。 例如, 您可以有一个限制, 如果脚本节点被添加到一个场景而不是对象上, 就可以检查。 或者如果脚本节点有没有孩子的限制, 也就是说它不能让任何孩子脚本节点连接到它 。
- 类型限制:这些限制定义了脚本节点的哪一种类型可以互相连接,例如,你可以允许一个"Event"类型的脚本节点只连接到"Action"类型的脚本节点.
- 标记限制:这些限制使得脚本节点只能连接到其他的脚本节点,即[have a specific tag](/editor/scene-editor/prefabs/prefab-tags).

*(更多关于[prefab tags](/editor/scene-editor/prefabs/prefab-tags)的学习) *

在连接 Scene 编辑器中的脚本节点时, 这些限制将会被考虑进去。 如果脚本节点不符合定义的限制, 它将无法连接到另一个对象。 因此, 用于连接的脚本节点所在的对话框将只显示那些符合您试图连接的对象的限制的对话框 。

以下图像显示在用户试图在"宠物列表"脚本中添加新的节点脚本时的 **Add Script** 对话框,如你所见,它只显示"宠物列表"的脚本,过滤出不符合"宠物列表"剧本节点预制体中定义的限制的脚本.

## 添加脚本节点的限制 {#adding-constraints-to-script-nodes}

正如我们在前几章中解释的那样,要创建自己的脚本节点,您必须创建脚本节点预制体文件。因此,必须在那里定义要应用到您的脚本节点的制约。

特别是,我们提出了检查专员意见中称为**Prefab control**的新一节,其中载有你已在prefab中添加的限制的列表,添加新限制的按钮(**Add Constraint**),以及您设定用于结合限制的逻辑运算符的参数。

![Prefab node constraints section](https://cdn.phaser.games/oss-docs/assets/fb05b36705e70ff2-script-node-constraints-section-20250801.webp)

### 限制清单 {#constraints-list}

限制列表显示您已经添加到预制体文件中的限制。 需要注意的是, 限制是继承的, 也就是说, 预制体变量继承了原始预制体变量的制约。 因此, 如果您添加了对预制体变量的制约, 则它将与所有继承的预制体变量结合 。

让我们看看一个例子,一个从一个**PetScript**预制体继承的**DogScript **预制体文件. 预制体文件**PetSclipt**有约束`Parent has tag "list of pets"`,预制体文件**DogSclipt **有约束`Child is instance of 'DogPartScript'`.

以下图像显示了检查专员对** DogScript** 预制体文件的看法。

![Prefab constraints inheritance](https://cdn.phaser.games/oss-docs/assets/fd3adc50d328174f-script-node-constraints-inheritance-2025.webp)

您只能删除本地约束, 而不是继承的。 如果您想要删除一个继承的制约, 您必须在父文件夹预览中进行 。

### 添加新的约束 {#adding-a-new-constraint}

**Add Controlint ** 按钮允许您在预制体文件中添加新的约束。单击此按钮将显示一个菜单,并带有可用的约束选项。 您可以在其中选择 :

- **父有标签** - 只有当父程序有特定标记时,才允许脚本节点连接。当您选择此选项时,将会出现一个对话框,您可以选择您想要用作约束的标记。
- **孩子有标签** - 允许一个孩子节点只有在孩子节点有特定标记的情况下才能连接到这个节点.
- **父母是** - 只有当其父为特定预制体文件或Phaser游戏对象类型时,才允许脚本节点连接。当您选择此选项时,将会出现一个对话框,您可以选择您想要用作约束的预制体文件或Phaser类型。
- **子对象是** - 允许一个孩子节点只有在孩子节点是特定预制体或Phaser游戏对象类型的实例时,才能连接到这个节点.
- **父母是现场** - 允许脚本节点只在父站点是场景时才能连接。这个约束对脚本节点是有用的,这些节点必须添加到场景中,而不是添加到特定的对象中。
- **不允许有孩子** 允许脚本节点没有连接到它的孩子节点。这个约束对不应该有孩子节点等级的脚本节点是有用的。

### 逻辑运算符 {#logic-operators}

** Contention ** 参数允许您设置用于组合本地约束的逻辑运算符。 您可以在 ** Match All ** 或 ** Match Any** 中选择。 匹配所有约束都意味着连接必须真实有效。 匹配任意则意味着连接必须至少有一个约束是真实的 。

** 继承条件** 参数允许您设置用于合并继承限制的逻辑运算符。 您可以在 ** Match All**, ** Match Any** 或 ** Override** 之间选择。 要确定连接是否有效, 系统首先检查继承的限制, 然后检查本地的限制, 然后在 ** 继承条件**中使用选定的运算符合并两个结果。 如果操作符被设定为:

- **全部匹配**: 继承的制约结果应当真实,地方制约结果必须真实,才能使连接有效.
- **全部匹配**: 继承的制约结果应该是真实的,或者当地制约结果必须是真实的,才能使连接有效.
- **覆盖**: 继承的制约结果被忽略,只有局部制约结果用于确定连接是否有效.

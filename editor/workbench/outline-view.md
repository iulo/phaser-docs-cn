# 大纲视图 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/outline-view)

大纲视图的目的是显示活动编辑器的内容,但具有层次结构.

一名编辑为《纲要》提供了内容,但也提供了上下文菜单和检查专员视图支持。

与其他[content viewers](/editor/misc/content-viewers)一样,它显示了各项目的内在预览,并且可以放大进出,内容可以过滤.

# 向文件添加动画 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/animations-editor/add-animation)

要创建新动画, 请按工具栏中的 ** Add 动画 ** 按钮。 它显示一个对话框以输入动画名称 :

![Create a new animation.](https://cdn.phaser.io/editor-docs/animations-add-animation-1.webp)

由于不允许空动画,它打开了对话框来选择最初动画的帧。如果选择一个纹理图集或图示表,所有帧都会被添加到动画中:

![Select the animation frames.](https://cdn.phaser.io/editor-docs/animations-add-animation-2.webp)![The new created animation.](https://cdn.phaser.io/editor-docs/animations-add-animation-3.webp)

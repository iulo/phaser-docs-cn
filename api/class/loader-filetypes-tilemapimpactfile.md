# TilemapImpactFile {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/loader-filetypes-tilemapimpactfile)

一个适合装入器装入的单一的 impact.js Tilemap JSON 文件 。

这些是使用Phaser.Loader.LoaderPlugin#tilemapImpact方法创建的,一般不直接创建.

关于所有参数和配置选项的文档,请参见Phaser.Loader.LoaderPlugin#tilemapImpact.

**构造函数**

`new TilemapImpactFile(loader, key, [url], [xhrSettings])`

**参数**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| loader | [Phaser.Loader.LoaderPlugin](/api/class/loader-loaderplugin) | 否 | 引用此文件的加载器 。 |
| key | string \| [Phaser.Types.Loader.FileTypes.TilemapImpactFileConfig](/api/typedef/types-loader-filetypes#tilemapimpactfileconfig) | 否 | 此文件使用的密钥, 或文件配置对象 。 |
| url | string | 是 | 从此文件加载的绝对或相对的 URL。 如果未定义或 `null` , 它将被设定为 `<key>.json`, 即如果 `key` 是"外国人", 那么 URL 将是"外国人. json" 。 |
| xhrSettings | [Phaser.Types.Loader.XHRSettingsObject](/api/typedef/types-loader#xhrsettingsobject) | 是 | 专门为此文件设置额外的 XHR 设置 。 |

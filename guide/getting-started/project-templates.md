# 项目模板 {#page-title}

Phaser 4 指南 · [英文原文](https://phaser.io/oss/docs/phaser/getting-started/project-templates)

Phaser支持所有主要的前端框架和捆绑器。模板都使用“ template” 设置在 GitHub 上显示, 允许您选择“ 使用此模板” 特性。 这样您就可以将模板复制到自己的仓库, 或者打开到 GitHub Codespaces 中 。

我们支持下列所有框架和组合:

| 框架 | 轮子 |
| --------- | ------- |
| 维耶 | 维特 |
| 反应 | 滚动 |
| 角形 | 纸 |
| 下一个.js | 网络软件包 |
| 固态JS | ES 构建 |
| 斯维尔特 | 导入地图 |
| 重混 | 包头 |

大部分都是JavaScript和TypeScript两种版本的.

## 框架模板 {#framework-templates}

从以下框架模板中选择:

* [React + Vite Template](https://github.com/phaserjs/template-react) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-react-ts)使用
* [Vue 3 + Vite Template](https://github.com/phaserjs/template-vue) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-vue-ts)使用
* [Angular + Vite Template](https://github.com/phaserjs/template-angular)
* [Svelte Template](https://github.com/phaserjs/template-svelte)
* [NextJS Template](https://github.com/phaserjs/template-nextjs)
* [SolidJS + Vite Template](https://github.com/phaserjs/template-solid)
* [Remix Template](https://github.com/phaserjs/template-remix)

## 打包工具模板 {#bundler-templates}

我们也有纯的捆绑模板,不需要使用任何框架。从中选择:

* [Vite Template](https://github.com/phaserjs/template-vite) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-vite-ts)使用
* [Webpack Template](https://github.com/phaserjs/template-webpack) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-webpack-ts)使用
* [ESBuild Template](https://github.com/phaserjs/template-esbuild) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-esbuild-ts)使用
* [Rollup Template](https://github.com/phaserjs/template-rollup) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-rollup-ts)使用
* [Parcel Template](https://github.com/phaserjs/template-parcel) - 也可作为[TypeScript Template](https://github.com/phaserjs/template-parcel-ts)使用
* [Import Map Template](https://github.com/phaserjs/template-importmap)
* [Bun Template](https://github.com/phaserjs/template-bun)

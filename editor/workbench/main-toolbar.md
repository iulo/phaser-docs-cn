# 主工具栏 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/main-toolbar)

主工具栏放置在窗口的顶端,工具栏分为左,中,右三个区域.

左侧区域有按钮可以触发全局命令:

* 打开[New File dialog](/editor/workbench/new-file-dialog)。
* [Play the project](/editor/workbench/playing-project).
* [Quick search](/editor/scene-editor/misc#go-to-dialog).
* [Open external code editor](https://phaser.io/oss/docs/phaser-editor/code-editor/intro.md#visual-studio-code--phaser-editor-integration).

中心区域是动态的。 其内容由活动编辑器提供。 这意味着, 显示在其中的按钮只影响活动编辑器。 例如, 场景编辑器将转换命令贡献给工具栏的中心区域。 如果编辑器关闭, 按钮将被删除 。

右侧区域显示一个打开支持聊天窗口的按钮,其他则显示打开[Main menu](/editor/workbench/main-menu).

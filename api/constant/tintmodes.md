# TintModes {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/constant/tintmodes)

### MULTIPLY {#MULTIPLY}

#### MULTIPLY: number {#multiply-number}


**说明:**

倍数锡模式( 默认) 。 锡的颜色与纹理颜色相乘 。


> 源码：[src/renderer/TintModes.js#L20](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L20)  
引入版本：4.0.0


### FILL {#FILL}

#### FILL: number {#fill-number}


**说明:**

填充色调模式。 色调取代纹理颜色, 但尊重纹理α 。

您可以使用此模式来使游戏对象如果被击中的话闪出“ 白色 ” 。


> 源码：[src/renderer/TintModes.js#L30](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L30)  
引入版本：4.0.0


### ADD {#ADD}

#### ADD: number {#add-number}


**说明:**

添加色素模式。 色素颜色被添加到纹理颜色中, 但尊重纹理α 。


> 源码：[src/renderer/TintModes.js#L43](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L43)  
引入版本：4.0.0


### SCREEN {#SCREEN}

#### SCREEN: number {#screen-number}


**说明:**

屏幕颜色模式。 颜色颜色会亮亮纹理的暗区域 。


> 源码：[src/renderer/TintModes.js#L57](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L57)  
引入版本：4.0.0


### OVERLAY {#OVERLAY}

#### OVERLAY: number {#overlay-number}


**说明:**

叠加的锡金模式 锡金颜色会亮亮区域 暗暗区域


> 源码：[src/renderer/TintModes.js#L67](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L67)  
引入版本：4.0.0


### HARD_LIGHT {#HARD_LIGHT}

#### HARD_LIGHT: number {#hard_light-number}


**说明:**

硬色色 : 色色 亮色 和 暗色 。 这就像覆盖, 但与 色色和纹理 色 互换 。


> 源码：[src/renderer/TintModes.js#L77](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/TintModes.js#L77)  
引入版本：4.0.0

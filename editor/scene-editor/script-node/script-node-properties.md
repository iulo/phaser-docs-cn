# 脚本节点的属性 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/script-node/script-node-properties)

脚本节点对象没有内置属性。 当您在现场选择脚本节点时, 检查器视图会显示几个仅与编辑器相关的段落 。

[Variable properties](/editor/scene-editor/game-objects/common-object-properties#variable-properties)就是这种情况。与游戏对象一样,一个脚本节点可以被变量引用,你可以将其范围设定为方法,类,或者声明为嵌套预制体:

![Variable section of a script node](https://cdn.phaser.io/editor-docs/script-node-variable-section-20230323.webp)

脚本节点也可以添加到[Object List](/editor/scene-editor/object-list)中:

![Object List section](https://cdn.phaser.io/editor-docs/scrip-node-object-list-section-20230323.webp)

因为可以作为预制体实例来创建,它显示了[Prefab Instance properties](/editor/scene-editor/prefabs/prefab-user-properties#user-properties-in-a-prefab-instance):

![Prefab instance properties.](https://cdn.phaser.io/editor-docs/script-node-object-list-section-20230627.webp)

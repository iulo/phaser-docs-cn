# 排序布局工具 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/layout-tools/layout-tools-sorting)

游戏对象在场景显示列表中有一个顺序,顺序是显示列表中游戏对象的索引,指数最低的游戏对象是第一个渲染对象,指数最高的游戏对象是最后一个渲染对象。在场景编辑器的大纲视图中,显示列表中最后一个对象是堆叠在大纲视图的顶端.

您可以使用排序命令来改变对象的顺序。 您可以执行上下文菜单。 请选择对象, 右键单击, 并选择 ** Edit** 子菜单 :

![Sorting commands in the Edit menu](https://cdn.phaser.io/editor-docs/scene-editor-sorting-commands-menu-20240918.webp)

查看它显示每个命令的键盘快捷键 。

此外,您还可以执行 [tools panel](/editor/scene-editor/misc#scene-tools-panel) 中的命令 :

![Sorting commands in the tools panel](https://cdn.phaser.io/editor-docs/scene-editor-sorting-commands-panel-20240918.webp)

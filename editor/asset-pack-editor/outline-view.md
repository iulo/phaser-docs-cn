# 在大纲视图中查看资源包 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/asset-pack-editor/outline-view)

通用大纲视图与活动 [Asset Pack Editor](/editor/asset-pack-editor/intro) 连接, 并显示所有按类型分类的文件配置。 对于复杂文件, 如地图集或图示表文件, 也显示框架 。

# Curve {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/gameobjects-curve)

曲线形状是一个游戏对象,可以添加到景物,组或容器中。您可以把它像游戏中其它任何游戏对象一样对待,比如对它进行曲折,缩放,或者允许它输入或物理。它为您提供了快速和容易的方法,可以在游戏中不使用纹理来渲染此形状,同时仍然利用WebGL进行完整的批量处理.

此形状支持设置填充颜色和描边颜色。

要制作出曲线形状, 您必须先创建 `Phaser.Curves.Curve` 对象, 然后传递到构造器中的曲线形状 。

曲线形状还具有`smoothness`属性和相应的`setSmoothness`方法。这允许您通过控制构造过程中发生的迭代数量来控制形状在WebGL中是如何平滑的。 增减更平滑或更划线的形状的默认值。

**构造函数**

`new Curve(scene, [x], [y], [curve], [fillColor], [fillAlpha])`

**参数**
| 名称 | 类型 | 可选 | 默认值 | 说明 |
| ---- | ---- | -------- | ------- | ----------- |
| scene | [Phaser.Scene](/api/class/scene) | 否 |  | 此游戏对象所属的景点。 一个游戏对象只能一次属于一个景点 。 |
| x | number | 是 | 0 | 这个游戏对象在世界的横向位置. |
| y | number | 是 | 0 | 此游戏对象在世界的垂直位置 。 |
| curve | [Phaser.Curves.Curve](/api/class/curves-curve) | 是 |  | 用于创建形状的曲线对象 。 |
| fillColor | number | 是 |  | 曲线的颜色会填充,即0xff000为红色. |
| fillAlpha | number | 是 |  | 曲线的α将被填充。您也可以使用其`alpha`属性设置整体形状的α 。 |

### setSmoothness {#setSmoothness}

#### \<instance> setSmoothness(value) {#instance-setsmoothnessvalue}


**说明:**

设置曲线的平滑度。 渲染时使用的点数。 增加此数值用于更平滑的曲线, 以获得更多多边形为代价。 此调用可以连锁。

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| value | number | 否 | 设置光滑度的值 。 |


**返回值:** [Phaser.GameObjects.Curve](/api/class/gameobjects-curve) - 此游戏对象实例 。

# 布局工具 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/layout-tools)

将对象放在场景中是场景编辑器提供的最吸引人的功能之一。布局工具是调整和分配场景对象的快捷键。您可以在布局上下文菜单或布局工具栏中找到工具。

这样做是:

- 选择要布局的对象 :
- 执行布局操作,在布局上下文菜单或布局工具栏中选择布局工具。您可以撤销或重做此操作 :

  ![Apply layout.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-steps-2-20220812.webp)

- 如果工具需要参数,请将它们设置在布局工具栏的参数框中:

  ![Apply layout](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-steps-2.1-20220812.webp)

您可以通过检查布局菜单中的 ** 显示布局栏** 选项来显示/隐藏布局工具栏 :

![Show/hide layout toolbar.](https://cdn.phaser.io/editor-docs/scene-editor-layout-tools-show-07092021.webp)

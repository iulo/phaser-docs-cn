# FilterBarrel {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/renderer-webgl-rendernodes-filterbarrel)

将枪管(或针)扭曲效果应用到WebGL的靶子上的RenderNode。Barrel扭曲将图像扭曲为向曲线表面投射的形状:正数向外(弹管)俯冲边缘,负数则向内(弹管)捏。它通常用于模拟鱼眼镜、VR屏幕曲率或反向CRT监测效果。

这个节点由[Phaser.Filters.Barrel](/api/class/filters-barrel)滤波控制器内部使用,它暴露了`amount`属性来控制扭曲的强度和方向.

见[Phaser.Filters.Barrel](/api/class/filters-barrel).

**构造函数**

`new FilterBarrel(manager)`

**参数**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| manager | [Phaser.Renderer.WebGL.RenderNodes.RenderNodeManager](/api/class/renderer-webgl-rendernodes-rendernodemanager) | 否 | 这个RenderNode的经理 |

## 公开方法 {#public-methods}

### setupUniforms {#setupUniforms}

#### \<instance> setupUniforms(controller, drawingContext) {#instance-setupuniformscontroller-drawingcontext}


**说明:**

设置枪管扭曲片段遮蔽器所需的遮蔽制服。从过滤器控制器读取 `amount`值,然后传递到GPU程序,它控制着对渲染目标应用的扭曲的强度和方向.

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| controller | [Phaser.Filters.Barrel](/api/class/filters-barrel) | 否 | 提供 `amount` 统一值的过滤控制器 。 |
| drawingContext | [Phaser.Renderer.WebGL.DrawingContext](/api/class/renderer-webgl-drawingcontext) | 否 | 当前绘图背景 。 |


**Overrides:** Phaser.Renderer.WebGL.RenderNodes.BaseFilterShader#setupUniforms

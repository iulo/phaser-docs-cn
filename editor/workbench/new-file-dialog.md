# 新建文件对话框 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/new-file-dialog)

** 新文件对话框 ** 显示您可以创建的不同类型文件。 当您选择一类文件时, 它会启动一个专用对话框来创建文件。 这些特定文件对话框是由不同的插件贡献的 。

![New File dialog.](https://cdn.phaser.games/oss-docs/assets/f71a895c62b0d5ad-workbench-new-file-dialog-20241223.webp)

要打开新文件对话框, 您可以点击 [Main toolbar](/editor/workbench/main-toolbar) 的 ** 新文件 ** 按钮, 或者按 `Ctrl+Alt+N` 键 。

![New File button in the toolbar.](https://cdn.phaser.games/oss-docs/assets/f122971ff8e22e5b-workbench-new-file-button-20241223.webp)

# 资源块视图 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/blocks-view)

Blocks 视图显示当前编辑器的构件。 这是一个与其他视觉工具稍有不同的概念 。

其他视频游戏创建工具中常见的是提供资源浏览器,显示项目中所有的资源.

块视图只显示在特定编辑器中可以使用的资源,或“块”。

例如,在[Asset Pack Editor](/editor/asset-pack-editor/intro)中,用户会向[Asset Pack file](/editor/asset-pack-editor/asset-pack-file)添加文件。这些文件在块视图中显示为块,但当用户向编辑器添加文件时,该文件会隐藏在块视图中,因为它已经存在.

检查器视图显示块视图中选择的元素的属性,或者您可以应用到这些元素的操作中.

块视图是 [content viewer](/editor/misc/content-viewers):它显示其元素的内含预览,你可以放大和退出,过滤其内容.

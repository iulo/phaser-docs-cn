# 编辑器内容布局 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/asset-pack-editor/editor-content-layout)

[Asset Pack Editor](/editor/asset-pack-editor/intro)的布局专注于提供视觉和辅助体验. 编辑器被分成若干节,每个节都专门用于某个特定的文件类型. 该科内部,文件配置以列布局显示.

编辑器使用[content viewer](/editor/misc/content-viewers),因此它显示元素的内含预览,可以放大进出(按下`Shift`和滚动鼠标轮),并过滤其上下文.

此外,"大纲"观点还提供了编辑内容的分级呈现.

# 主菜单 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/main-menu)

[Main menu](/editor/workbench/main-menu) 列出常见的普通命令。 您可以在 [Main toolbar](/editor/workbench/main-toolbar) 右侧的菜单按钮中按下它 :

![Main menu.](https://cdn.phaser.games/oss-docs/assets/265c1879d4de1ab0-workbench-main-menu.webp)
* **打开工程**: 启动本地目录选择器以打开新项目。
* **关闭工程**: 关闭当前工程,返回 [Start page](/editor/first-steps/create-first-project) 。
* **重新装入工程**: [reloads the project files](/editor/workbench/projects#reload-project).
* **编译工程**: 编译工程的所有可编译文件。 例如, [scene](/editor/scene-editor/scene-compiler) 和 [component](/editor/scene-editor/user-components/user-components-compiler) 文件。 这不包括 TypeScript 文件或带有外部编译器的任何其他格式 。
* **开放视觉工作室代码**: 以本地 [Visual Studio Code](https://code.visualstudio.com) 实例打开工程。 只有在 Phaser编辑器服务器在 [desktop mode](/editor/misc/server-options) 中运行时, 才可用此选项。 您可以配置不同的外部编辑器。 请检查 ** 外部编辑器- 命令 ** [server option](/editor/misc/server-options) 。
* **版式**: 它显示了一个支持的[window layouts](/editor/workbench/layouts)列表.
* **选择颜色主题**: 打开[Color Themes dialog](/editor/workbench/color-themes)。
* **命令调色板**: 打开[Command Palette](/editor/workbench/command-palette)。
* **设置**: 打开[Settings dialog](/editor/workbench/settings)。
* **检查更新**: 检查是否有新版本 。
* **Phaser 探索器**: 打开带有 [Phaser Explorer](https://explorer.phaser.io)的新窗口,这是浏览 Phaser API 和示例的高级工具.
* **帮助**: 在浏览器中打开此文档。
* **关于**: 打开“关于”对话框。

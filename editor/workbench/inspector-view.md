# 检查器视图 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/inspector-view)

检查器视图显示在活动视图或编辑器中选择的对象的属性 。

属性被分组为区块, 区块可以崩溃或扩展 。

属性的标签支持工具提示。 通常, 这个工具提示是属性的通讯器 [Phaser API](https://phaser.io/oss/docs/docs/latest.md) 文档 。

除了常见的属性,一个部分还可以显示预览图像或按钮,以将某些操作应用到选定的对象上.

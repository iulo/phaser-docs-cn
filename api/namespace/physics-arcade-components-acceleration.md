### setAcceleration {#setAcceleration}

#### \<instance> setAcceleration(x, [y]) {#instance-setaccelerationx-y}


**说明:**

设置机体的横向和纵向加速。如果不提供纵向加速值,则垂直加速值设定为与横向加速值相同的数值。

**参数:**
| 名称 | 类型 | 可选 | default | 说明 |
| ---- | ---- | -------- | ------- | ----------- |
| x | number | 否 |  | 水平加速度,以像素每秒平方英寸表示. |
| y | number | 是 | "x" | 垂直加速,以每秒平方像素计. |


**返回值:** [Phaser.Physics.Arcade.Components.Acceleration](/api/namespace/physics-arcade-components-acceleration) - 此游戏对象 。


> 源码：[src/physics/arcade/components/Acceleration.js#L15](https://github.com/phaserjs/phaser/blob/v4.1.0/src/physics/arcade/components/Acceleration.js#L15)

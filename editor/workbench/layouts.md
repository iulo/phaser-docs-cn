# 窗口布局 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/layouts)

您可以改变窗口中视图和编辑器的布局.

在 [main menu](/editor/workbench/main-menu) 中扩展 ** Layout ** 子菜单,并选择一个选项:

![Layout menu](https://cdn.phaser.io/editor-docs/workbench-layout-menu-20240423.webp)

** 默认布局** 显示所有视图。 文件夹中的每个视图 :

![Default Layout](https://cdn.phaser.io/editor-docs/workbench-layout-default-20240423.webp)

** Large Scene 版式** 重新排列视图,用 [Outline view](/editor/workbench/outline-view) 折叠 [Files view](/editor/workbench/files-view), 给编辑器区域所有垂直空间 :

![Large Scene Layout](https://cdn.phaser.io/editor-docs/workbench-layout-large-scene-20240423.webp)

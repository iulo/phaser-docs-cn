# 可编辑的瓦片地图图层 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/game-objects/editable-tilemap-layer-object)

**可分配的斜拉层** 是类型对象 [Phaser.Tilemaps.TilemapLayer](/api/class/tilemaps-tilemaplayer) 使用 [tilemap editor](/editor/scene-editor/game-objects/editable-tilemap-object) 列入 Phaser 编辑器。 此对象类似于 [TilemapLayer](/editor/scene-editor/game-objects/tilemap-layer-object) 只能从第三方工具设计的外部文件中装入图版,而可以在场景编辑器中编辑可编辑的图版图层。

当您选择了这种对象时, 您可以执行所有游戏对象的常见操作, 例如编辑、 删除、 在显示列表中移动 等. 然而, 您通常需要做的是编辑其内容, 拼图。 要做到这一点, 您必须选择它属于的拼图并使用所提供的工具。 请点击 ** Edit Map ** 按钮或按 `P`Z 键。 您可以在 [EditableTilemapLayer](/editor/scene-editor/game-objects/editable-tilemap-object) 的章节中找到编辑地图的指南 。

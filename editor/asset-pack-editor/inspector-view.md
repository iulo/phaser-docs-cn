# 在检查器视图中编辑资源包 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/asset-pack-editor/inspector-view)

检查器视图与活动 [Asset Pack Editor](/editor/asset-pack-editor/intro) 连接,并显示属性编辑器以更改文件配置 。

除了属性编辑器之外,在某些情况下,检查专员视图还显示所选配置的预览.

此预览部分在您选择 IDE 其它部分的文件键时显示, 如 Scene 编辑器中的块视图 。

# 什么是 Phaser？ {#page-title}

Phaser 4 指南 · [英文原文](https://phaser.io/oss/docs/phaser/getting-started/what-is-phaser)

Phaser 是一个免费、开源的 HTML5 游戏框架，支持在桌面和移动浏览器中使用 WebGL 或 Canvas 渲染，已经持续开发十余年。

你可以把游戏发布到网页、YouTube Playables、Discord Activities 或 Twitch Overlay，也可以借助第三方工具将游戏打包到 iOS、Android、Steam 等平台。Phaser 支持 JavaScript 和 TypeScript，并可与 React、Vue 等四十多种前端框架配合使用。

Phaser 由 Phaser Studio Inc. 和开源社区共同开发维护。它拥有面向开发者的 API，并得到持续支持，是 GitHub 上[获得星标最多的游戏框架之一](https://github.com/collections/javascript-game-engines)。

## Phaser 可以用来做什么？ {#what-is-it-used-for}

Phaser 使用 Web 技术开发，面向浏览器游戏。游戏可以在桌面或移动浏览器中运行，也可以嵌入 Discord、Snapchat 或 Facebook 等支持网页游戏的应用。通过第三方工具，还能将浏览器游戏打包成移动或桌面原生应用。

框架的功能和内部设计围绕高性能 2D 游戏展开。需要 3D 渲染或 3D 物理时，可以集成第三方库。官方文档和示例聚焦 2D 功能。

Phaser 用 JavaScript 编写。开发游戏时可选 JavaScript 或 TypeScript，官方示例使用 JavaScript，并提供 TypeScript 类型声明。

Phaser 以 JavaScript 库的形式提供。你可以下载库文件、使用 CDN，或通过 npm 等包管理器安装。在页面中引入它或将它打包进项目，再用浏览器运行游戏代码。需要可视化编辑工具时，可以使用 Phaser Editor。

Phaser 有一支专职团队持续维护，注重稳定性和学习体验。开发者已经用它制作了数千款游戏，从小型原型到拥有数百万玩家的商业作品。

## 哪些项目需要其他工具？ {#when-is-phaser-not-the-right-choice}

如果项目需要完整的 3D 功能、计划在 PS5、Xbox 或 Nintendo Switch 等主机发布，或者需要无代码编辑器，可以考虑面向这些场景的工具。Phaser 适用于用 JavaScript 或 TypeScript 开发网页 2D 游戏。

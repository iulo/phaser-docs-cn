# 命令面板 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/workbench/command-palette)

命令调色板是一个对话框,它显示当前上下文**中可用的命令。您可以按下 `Ctrl+K`或点击 [Main menu](/editor/workbench/main-menu)的**命令调色板**选项打开它。

并非所有命令都显示,那些不适用于**当前上下文**(活动视图、活动编辑器或活动对话框)的命令则省略。

在对话框中,您可以按 **Execute ** 按钮选择一个命令并执行它 。

![Command palette dialog.](https://cdn.phaser.io/editor-docs/workbench-command-palette-04072020.webp)

命令由插件贡献给工作台.

您可以更改 [Keyboard settings](/editor/workbench/settings#keyboard-settings) 中命令的键绑定 。

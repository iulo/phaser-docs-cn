### LINEAR {#LINEAR}

#### LINEAR: number {#linear-number}


**说明:**

线性缩放模式。 缩放纹理时使用双线性插图, 产生平滑结果。 最适合非像素艺术图形, 以进行平滑缩放 。


> 源码：[src/renderer/ScaleModes.js#L26](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/ScaleModes.js#L26)  
引入版本：3.0.0


---

### NEAREST {#NEAREST}

#### NEAREST: number {#nearest-number}


**说明:**

最接近缩放模式。 缩放纹理时使用最近的邻居采样, 不插图保存硬像素边缘。 最适合像素艺术和反转风格图形 。


> 源码：[src/renderer/ScaleModes.js#L36](https://github.com/phaserjs/phaser/blob/v4.1.0/src/renderer/ScaleModes.js#L36)

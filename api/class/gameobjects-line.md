# Line {#page-title}

Phaser v4.1.0 · [英文原文](https://phaser.io/oss/docs/api-documentation/class/gameobjects-line)

Line 形状是游戏对象, 可以添加到游戏场景、 组合或容器中。 您可以把它当作游戏中的其他任何游戏对象, 如进行曲折、 缩放或允许输入或物理。 它为您提供了快速和容易的方法, 可以在游戏中不使用纹理来渲染此形状, 同时仍然利用在 WebGL 中被完全批量处理 。

此形状只支持中风颜色,不能填充 。

线条形状允许您在游戏中绘制两点之间的线条。 您可以控制线条的中风颜色和厚度。 在 WebGL 中, 您也可以指定线条的起始和结尾的厚度不同, 从而可以将线条切换为剪切线 。

如果您需要绘制序列中的多行, 您可能希望使用多边形形状代替 。

注意, 与所有游戏对象一样, 默认来源为 0. 0。 如果您需要在两点之间绘制一条线, 并且想要 x1/y1 值与 x/y 值匹配, 那么将来源设置为 0 。

**构造函数**

`new Line(scene, [x], [y], [x1], [y1], [x2], [y2], [strokeColor], [strokeAlpha])`

**参数**
| 名称 | 类型 | 可选 | default | 说明 |
| ---- | ---- | -------- | ------- | ----------- |
| scene | [Phaser.Scene](/api/class/scene) | 否 |  | 此游戏对象所属的景点。 一个游戏对象只能一次属于一个景点 。 |
| x | number | 是 | 0 | 这个游戏对象在世界的横向位置. |
| y | number | 是 | 0 | 此游戏对象在世界的垂直位置 。 |
| x1 | number | 是 | 0 | 线起处的横向位置. |
| y1 | number | 是 | 0 | 线条起始的垂直位置. |
| x2 | number | 是 | 128 | 线尾的横向位置. |
| y2 | number | 是 | 0 | 线尾的垂直位置. |
| strokeColor | number | 是 |  | 线条的颜色会被绘制为红色,即0xff000. |
| strokeAlpha | number | 是 |  | 线条的alpha 将被绘制。 您也可以使用它的 `alpha` 属性设置整个形状的alpha 。 |

## 公开方法 {#public-methods}

### setLineWidth {#setLineWidth}

#### \<instance> setLineWidth(startWidth, [endWidth]) {#instance-setlinewidthstartwidth-endwidth}


**说明:**

设置行宽度。

使用 WebGL 渲染器时,您可以有不同的起始宽度。使用 Canvas 渲染器时只使用 `startWidth` 值。 `endWidth` 被忽略 。

这个电话可以被锁起来。

**参数:**
| 名称 | 类型 | 可选 | 说明 |
| ---- | ---- | -------- | ----------- |
| startWidth | number | 否 | 线路的起始宽度 。 |
| endWidth | number | 是 | 线路的尾宽度,仅在WebGL中使用. |


**返回值:** [Phaser.GameObjects.Line](/api/class/gameobjects-line) - 此游戏对象实例 。


> 源码：[src/gameobjects/shape/line/Line.js#L111](https://github.com/phaserjs/phaser/blob/v4.1.0/src/gameobjects/shape/line/Line.js#L111)  
引入版本：3.13.0

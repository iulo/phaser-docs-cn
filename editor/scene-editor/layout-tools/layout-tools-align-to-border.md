# 边缘对齐工具 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/layout-tools/layout-tools-align-to-border)

和[Align tools](/editor/scene-editor/layout-tools/layout-tools-align)一样,对齐到边框的工具将对象放在一条线中,但这条线是边框或场景之一.

场景的边界设定在[Scene’s properties](/editor/scene-editor/scene-properties#border-properties)中.

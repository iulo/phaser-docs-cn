### ShaderAdditionConfig {#ShaderAdditionConfig}

#### ShaderAdditionConfig {#shaderadditionconfig}


**说明:**

阴影添加连接定义了要添加到着色器程序中的添加。它包括一个名称、一组阴影添加和可选标记。

名称被用作识别阴影添加的键。 它被用作着色器程序唯一标识符的一部分 。

着色器添加是键值对字符串,其中键是添加该值的模板。这在底着色器程序源代码中作为`#pragma phaserTemplate(key)`找到。

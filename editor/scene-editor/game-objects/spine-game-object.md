# Spine 游戏对象 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/game-objects/spine-game-object)

[Spine](https://esotericsoftware.com) 是一个流行且强大的编辑器,用于制作2D骨骼动画。它提供了一种 [official runtime](https://esotericsoftware.com/spine-phaser) 费用 Phaser.

[SpineGameObject](/editor/scene-editor/game-objects/spine-game-object)是用于显示和控制[Spine](https://esotericsoftware.com)动画的Phaser游戏对象.

电话 [Spine](https://esotericsoftware.com) Phaser 运行时间为装入、控制和自定义提供了丰富的功能集。 [Spine](https://esotericsoftware.com) 动画在 a 中 Phaser 游戏。所有这些功能都可以通过运行时间 API 获取。在 Phaser 编辑器作为一个附加,我们正在将基本和最重要的特征纳入视觉工具。这是一个渐进的过程,但目前的一套 [Spine](https://esotericsoftware.com) 由 Phaser 编辑器将帮助您整合 [Spine](https://esotericsoftware.com) 游戏中的动画,提升你的生产力.

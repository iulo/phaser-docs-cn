# Spine 游戏对象的用户属性 {#page-title}

Phaser Editor v5 · [英文原文](https://phaser.io/oss/docs/phaser-editor/scene-editor/spine-animations/spine-animations-game-object-user-properties)

在 Phaser 编辑器中,您可以将游戏对象行为概括为预制体, [user components](/editor/scene-editor/user-components), 和 [script nodes](/editor/scene-editor/script-node)。 这些机制使用 [user properties](/editor/scene-editor/prefabs/prefab-user-properties) 来自定义行为 。

为了更好地实施与[Spine](https://esotericsoftware.com)游戏对象相关的行为,我们提供了两种用户属性类型: .

* [Spine Skin Name property type](/editor/scene-editor/prefabs/prefab-user-properties#spine-skin-name-property-type)
* [Spine Animation Name property type](/editor/scene-editor/prefabs/prefab-user-properties#spine-animation-name-property-type)

此外,事件属性类型允许[Spine events](/editor/scene-editor/prefabs/prefab-user-properties#dynamic-spine-events).
